# Clínica Nutricional NutriVida

Proyecto académico de **Antonia Muñoz y Felipe Araya**, DSY1104 Desarrollo Fullstack II.

La versión React para la **Evaluación Parcial 2** está en [nutrivida-react](nutrivida-react). Revisa su README para instalar, ejecutar y probar. Los archivos HTML, CSS y JavaScript de la raíz se mantienen como referencia de la primera entrega.

## Inicio rápido

```sh
cd nutrivida-react
npm ci
npm run dev
npm run verify
```

## Entregables y evidencias

- [ERS V2 editable](nutrivida-react/docs/NutriVida_ERS_V2.docx) y [PDF](nutrivida-react/docs/NutriVida_ERS_V2.pdf)
- [Informe de testing](nutrivida-react/docs/NutriVida_Informe_Testing.pdf)
- [Guía de presentación](nutrivida-react/docs/Guia_presentacion.md)
- [Resultados y evidencias](nutrivida-react/docs/evidencias)

El proyecto utiliza datos locales y pagos simulados. No incluye un backend real ni cobros bancarios. El alcance y la adaptación de la tienda al caso de la clínica están detallados en el ERS.

La revisión 2.1 del ERS conserva los 29 requisitos de la planilla inicial y añade R.30 a R.42 para EP2. La sección 4.3 detalla diferencias pendientes: entre ellas filtro por modalidad, reprogramación, desactivación reversible, formato de RUN y alerta de cupos. No se declara aceptación completa de la propuesta inicial.
